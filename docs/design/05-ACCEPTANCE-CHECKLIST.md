# Критерии приёмки

## Визуальная часть

- [ ] Композиция узнаваемо опирается на референс: header + каталог + мозаичная витрина.
- [ ] Цветовая система оригинальная: графит, изумруд, золото.
- [ ] Нет логотипа, названий игр, персонажей и постеров из референса.
- [ ] CTA визуально доминирует, но интерфейс не перегружен свечением.
- [ ] Карточки имеют единые радиусы, границы, тени и правила изображений.
- [ ] На первом экране отсутствуют обрезанные тексты и случайный overflow.

## Функциональность

- [ ] Поиск фильтрует карточки.
- [ ] Категории работают и имеют активное состояние.
- [ ] Избранное переключается и сохраняется хотя бы в localStorage для демо.
- [ ] `Играть` открывает preview/confirmation, а не запускает фиктивную ставку.
- [ ] `Пополнить` открывает честную заглушку кассы.
- [ ] Есть loading, empty, error и unavailable состояния.

## Адаптивность

- [ ] Проверено на 1440, 1024, 768 и 390 px.
- [ ] На мобильном нет горизонтального overflow страницы.
- [ ] Touch targets минимум 44×44 px.
- [ ] Bottom navigation не перекрывает контент и учитывает safe-area.

## Доступность

- [ ] Полная клавиатурная навигация.
- [ ] Видимый focus state.
- [ ] Семантические кнопки и заголовки.
- [ ] Диалог имеет label, focus trap, Escape и возврат фокуса.
- [ ] Контраст соответствует WCAG AA.
- [ ] Reduced motion поддерживается.

## Качество кода

- [ ] Компоненты разделены по ответственности.
- [ ] Данные игр вынесены из JSX.
- [ ] Цвета и размеры управляются токенами.
- [ ] TypeScript strict не выдаёт ошибок.
- [ ] Lint, tests и production build проходят.
- [ ] Нет ключей, реальных платёжных вызовов и клиентской логики расчёта выигрышей.

## Регуляторная готовность UI

- [ ] Видна маркировка 18+.
- [ ] Есть ссылки на ответственную игру, правила, конфиденциальность и лицензионную информацию.
- [ ] Предусмотрены лимиты и самоисключение в профиле.
- [ ] Юридические тексты и доступность по географии загружаются из конфигурации, а не захардкожены в компонентах.
