# Casino Lobby UI — дизайн-пакет для coding agent

Этот пакет описывает оригинальный интерфейс игрового лобби, вдохновлённый компоновкой приложенного референса, но не копирующий его бренд, логотип, персонажей, постеры или графические материалы. В составе полного проекта инструкции запуска находятся в корневых `AGENTS.md`, `START-HERE.md` и `prompts/`.

## Как использовать

1. Используйте скриншот `../reference/lobby-reference.png` только как композиционный референс.
2. Coding agent обязан прочитать весь дизайн-пакет.
3. Файл `00-DESIGN-BRIEF.md` задаёт визуальную цель, а корневой мастер-промт — текущий объём реализации.
4. Следуйте фактическому стеку и командам репозитория.
5. Проверьте экран на ширинах 1440, 1024, 768 и 390 px.

## Состав

- `00-DESIGN-BRIEF.md` — визуальное задание.
- `01-PRODUCT-AND-UX.md` — назначение, структура и поведение.
- `02-VISUAL-SYSTEM.md` — новая визуальная система и дизайн-токены.
- `03-COMPONENTS.md` — компоненты и их состояния.
- `04-IMPLEMENTATION.md` — технические правила и архитектура.
- `05-ACCEPTANCE-CHECKLIST.md` — критерии готовности.

## Важное ограничение

Референс используется только для понимания композиции и плотности интерфейса. Все названия, логотипы, иллюстрации, игровые обложки и иконки должны быть новыми или лицензированными для проекта.
