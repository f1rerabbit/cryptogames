# Зафиксированные решения

## Сейчас

- Продукт: responsive web platform + отдельная web admin.
- Первые 3 мастер-промта создают MVP без настоящих игр и криптовалюты.
- Test asset: `TSC` — Test Satoshi Credit, integer units, non-withdrawable.
- Игровая интеграция сначала проверяется через deterministic provider simulator.
- Денежный источник истины: append-only double-entry ledger.
- Дизайн: оригинальная Midnight Emerald, референс только по композиции.
- Локальная/серверная разработка: Docker Compose.
- Real Bitcoin: не раньше Prompt 5.

## Требуют решения до Prompt 5

- лицензия и юрисдикция;
- разрешённые страны;
- собственный custody либо внешний provider;
- multisig/MPC/HSM модель;
- Bitcoin on-chain и/или Lightning;
- confirmation/fee/limit policies;
- KYC/AML, sanctions и blockchain analytics vendors;
- real game aggregator/providers;
- production hosting topology и RPO/RTO.
